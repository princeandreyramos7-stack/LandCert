# Admin Review Workflow - Quick Start Guide

**For:** Admin Users  
**Feature:** One-Click Application Review System

---

## 🎯 WHAT'S NEW?

Instead of the old complex review process, you can now review or reject applications with **ONE streamlined action**:

1. **Click "Review"** → Modal opens
2. **Select action**: ✅ Reviewed or ❌ Reject
3. **Fill details** → Submit
4. **Done!** SuperAdmin approves, applicant gets notified

---

## 📋 HOW TO REVIEW AN APPLICATION

### **Step 1: Navigate to Applications**
1. Login as Admin
2. Go to **Admin Dashboard** → **Applications**
3. You'll see all applications with their status

### **Step 2: Click "Review" Button**
- Find the application you want to review
- Click the blue **"📋 Review"** button
- **Note:** Button only shows for **pending** applications

### **Step 3: Choose Your Action**

#### **Option A: ✅ REVIEWED (Approve & Set Details)**

When you select "REVIEWED", you'll set:

**1. Appointment Details:**
- **Date:** Pick a future date when applicant should come
- **Time:** Choose from 08:00 AM - 04:00 PM

**2. Payment Information:**
- Enter the amount applicant needs to pay (in Pesos)
- Example: 500.00, 1000.00, 1500.00

**3. Requirements Needed:**
- **Auto-populated** based on application type:
  - **SUP (Special Use Permit)**: Barangay Clearance, Tax Declaration, Vicinity Map, etc.
  - **TUP (Temporary Use Permit)**: Barangay Clearance, Valid ID, Location Sketch, etc.
  - **Zoning Clearance**: Barangay Clearance, Tax Declaration, Title, Location Plan, etc.
- Required items are **automatically checked**
- You can check/uncheck any requirement
- Add custom requirements if needed

**4. Admin Notes (Optional):**
- Add any special instructions or notes
- Example: "Please bring original documents, not photocopies"
- Max 1000 characters

**5. Submit:**
- Click **"Submit Review"** button
- Application status → "Pending SuperAdmin Approval"
- SuperAdmin gets notified
- Once SuperAdmin approves, applicant receives email with ALL details

---

#### **Option B: ❌ REJECT (Decline Application)**

When you select "REJECT", you'll provide:

**1. Rejection Reason:**
- **Required:** Must explain why application is rejected
- Be clear and specific so applicant knows what to fix
- Max 1000 characters

**2. Quick Select Buttons:**
- Click any button to auto-fill common reasons:
  - "Incomplete Documents"
  - "Invalid Location"
  - "Zoning Violation"
  - "Missing Information"
- You can edit the text after clicking

**3. Submit:**
- Click **"Submit Review"** button
- Application status → "Rejected"
- Applicant receives **immediate** email + SMS notification
- No SuperAdmin approval needed for rejections

---

## 📧 WHAT HAPPENS AFTER REVIEW?

### **If You Selected "REVIEWED":**
1. ✅ Application marked as "Pending SuperAdmin Approval"
2. ✅ SuperAdmin receives notification
3. ✅ SuperAdmin reviews and clicks "Approve"
4. ✅ Applicant receives comprehensive email with:
   - Appointment date & time
   - Payment amount
   - Requirements checklist
   - Your admin notes
   - Office location & hours
5. ✅ Payment reminder scheduled (3 days)
6. ✅ SMS sent (if phone number available)

### **If You Selected "REJECT":**
1. ❌ Application marked as "Rejected"
2. ❌ Applicant receives immediate email with rejection reason
3. ❌ SMS sent (if phone number available)
4. ❌ No SuperAdmin action needed

## 💡 TIPS & BEST PRACTICES

### **For Appointment Scheduling:**
- ⏰ **Avoid Mondays & Fridays** - usually busiest
- ⏰ **Morning slots (09:00-11:00)** - recommended
- ⏰ **Space appointments** - allow 30-60 min per applicant
- ⏰ **Check calendar** - don't double-book

### **For Setting Payment Amount:**
- 💰 **Check fee schedule** - use official rates
- 💰 **Include all fees** - processing + other charges
- 💰 **Round to whole numbers** - easier for cash payments
- 💰 **Document basis** - add note if special case

### **For Requirements:**
- 📋 **Use auto-populated list** - ensures consistency
- 📋 **Check required items** - already marked as required
- 📋 **Add specifics in notes** - e.g., "2 photocopies of each"
- 📋 **Verify project type** - determines requirements

### **For Rejection Reasons:**
- ✍️ **Be specific** - don't just say "incomplete"
- ✍️ **List missing items** - help them fix issues
- ✍️ **Be professional** - maintain respectful tone
- ✍️ **Offer guidance** - suggest how to correct

## ❓ COMMON QUESTIONS

### **Q: Can I edit a review after submitting?**
**A:** Not directly. You'll need to:
1. Contact SuperAdmin to hold approval
2. Admin can submit a new review
3. Latest review overwrites previous

### **Q: What if applicant needs different requirements?**
**A:** 
- Uncheck auto-selected items
- Add custom requirement using "Other (specify)" option
- Add explanation in Admin Notes

### **Q: Can I schedule appointment for today?**
**A:** No, system only allows future dates. This gives applicant time to prepare.

### **Q: What if applicant misses appointment?**
**A:** 
- Contact applicant to reschedule
- SuperAdmin can update appointment details
- Or create new review with updated date

### **Q: How long before SuperAdmin approves?**
**A:** 
- Usually within 24 hours
- SuperAdmin gets immediate notification
- You can follow up if urgent

### **Q: Can I review multiple applications at once?**
**A:** Not yet - current version is one-by-one. Batch review feature planned for Phase 2.

## 🚨 TROUBLESHOOTING

### **Problem: "Review" button doesn't show**
**Solutions:**
- Check application status - must be "pending"
- Refresh the page
- Check if you have admin permissions

### **Problem: Requirements not loading**
**Solutions:**
- Check if project type is set
- Refresh modal by closing and reopening
- Contact tech support if persists

### **Problem: Can't submit review**
**Solutions:**
- Check all required fields are filled
- Verify appointment date is in future
- Check payment amount is positive number
- For rejection, ensure reason is not empty

### **Problem: SuperAdmin not receiving notification**
**Solutions:**
- Verify SuperAdmin users exist in system
- Check notification settings
- Contact tech support
